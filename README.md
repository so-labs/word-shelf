# Word Shelf

IMEのユーザー辞書を管理するためのWebツールです。辞書データを1つの正本ファイルで管理し、Google日本語入力／Gboard用とMicrosoft IME用の辞書ファイルを出力します。

データはブラウザの中だけで処理され、サーバーへ送信されることはありません。保存先は正本ファイルのみで、アプリ内に辞書データを恒常的に保存することもありません。

## 1. 正本ファイル形式

正本は `DictionaryMaster.tsv` とし、形式は次のとおり厳密に定めます。

- 文字コード: UTF-8（BOMなし）
- 改行: LF
- 1行目はヘッダー行: `Primary` / `Secondary` / `読み` / `単語` / `品詞` / `コメント` の6列
- 区切り: タブ
- 先頭が `=` のセルは、先頭に `'` を付けた形で保存します（読み込むときに `'` を取り除きます）

## 2. 出力ファイル

|ファイル|対象|形式|
|---|---|---|
|`DictionaryMaster.tsv`|正本|上記の正本形式（6列）|
|`Dictionary_GoogleIME.txt`|Google日本語入力／Gboard|UTF-8（BOMなし）・LF、読み／単語／品詞／コメントの4列、ヘッダーなし|
|`Dictionary_MicrosoftIME.txt`|Microsoft IME|UTF-16LE（BOM付き）・CRLF、読み／単語／品詞（コメントがある行のみ4列目にコメント）|

品詞はGoogle日本語入力の品詞体系（45種）を正本の基準とします。Microsoft IME用に出力する際は品詞を変換表で変換し、対応する品詞がないもの（サジェストのみ、抑制単語、終助詞、動詞ハ行四段、動詞カ変／サ変／ザ変／ラ変）はMicrosoft IME用の出力に含めません。

## 3. 使い方

1. 正本ファイル（`DictionaryMaster.tsv`）を開きます（空の辞書から新規作成もできます）。
2. 一覧で検索・絞り込みをしながら、追加・編集・削除をします。編集中の内容は画面の中だけにあり、ファイルにはまだ保存されません。
3. 「出力」の「まとめてダウンロード」で、正本ファイルとIME用辞書ファイルをまとめてダウンロードします。正本は保存忘れを防ぐため常時含まれ、IME用辞書ファイルはチェックボックスで含めるものを選べます（既定は両方）。ダウンロードするまで、画面には「未出力」の表示が残ります。

一覧の既定の並び順は、分類（Primary→Secondary）→読み順です。分類はチップ（Primary）と絞り込みシート（Secondary）で絞り込めます。検索は読み・単語・分類・コメントが対象で、単語・読みに一致したものを先に表示します。

未出力の編集中の内容は、この端末のブラウザへ自動で一時退避されます。リロードや開き直しをしても、次に開いたときに復元するか聞かれるので、作業を中断しても続きから再開できます。ただし一時退避は保険であり、正式な保存は正本ファイルのダウンロードだけです。

テーマは、ヘッダーの「⚙ 設定」からライト／システム／ダークを切り替えられます。使い方の詳しい説明も、設定からいつでも読み返せます。スマートフォンでは、ブラウザのメニューからホーム画面に追加すると、アプリとして起動できます。

## 4. 開発

```bash
cd app
npm install
npm run dev     # 開発サーバー
npm run build   # 型チェックとビルド
npm test        # 変換ロジックの自動テスト
npm run roundtrip -- <DictionaryMaster.tsv のパス> [出力先ディレクトリ]  # 往復検証CLI
```
